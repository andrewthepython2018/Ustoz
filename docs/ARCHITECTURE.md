# Устройство Ustoz

React 19 + TypeScript, маршруты App Router через Vinext/Vite, сервер Cloudflare Workers, SQL-база D1 (SQLite), приватное файловое хранилище R2. Исходники и миграции принадлежат репозиторию: проект можно развернуть в собственном Cloudflare-аккаунте без Sites.

## Роли

| Роль | Доступ |
| --- | --- |
| Гость | Каталог, поиск, фильтры, анкеты, свободные слоты, отзывы |
| Ученик | Запись и отмена, свои занятия, ответы на задания и файлы, сообщения преподавателям, избранное, отзывы после завершённого занятия |
| Преподаватель | Собственные предложения и слоты, ученики своих занятий, задания, проверка, ссылки на видеоуроки, сообщения |
| Учебный центр | Те же возможности для курсов; групповые слоты от 1 до 30 мест |
| Администратор | Просмотр пользователей и модерация публикаций |

Роль выбирается при регистрации и не меняется через редактирование профиля. Администратор не может зарегистрироваться через публичную форму. Владелец назначает роль `admin` существующему пользователю через защищённую консоль D1; не следует менять роль единственного преподавательского аккаунта, если он продолжает вести занятия.

Каждое действие проверяется в `app/api/[...path]/route.ts`. ID из браузера не является доказательством доступа. SQL использует подготовленные выражения. Файлы выдаются только ученику или преподавателю соответствующего задания, с `Content-Disposition: attachment`.

## Данные и время

`users → listings → slots → bookings → assignments → submissions` описывает основной учебный сценарий. `messages`, `favorites`, `reviews`, `sessions`, `rate_limits` отвечают за остальные возможности. Время в БД — ISO 8601 / UTC; формы и отображение — Asia/Tashkent / UTC+5. Ограничение мест и пересечения проверяются в SQL-операции записи, а уникальный частичный индекс запрещает дублировать активную запись одного ученика на один слот.

Преподаватель открывает слоты для индивидуальных уроков; центр указывает вместимость группы. Заявка сразу подтверждается. Отмена до начала освобождает место. Завершение доступно преподавателю после окончания занятия. Фиксация статуса «завершено» даёт ученику возможность оставить отзыв.

## Авторизация

Обычная регистрация email + пароль работает без внешних сервисов. Пароли хешируются PBKDF2-SHA256 с уникальной солью; в БД хранятся хеши сессионных токенов. Cookie — HttpOnly, SameSite=Lax и Secure на HTTPS. Сессия действует 14 дней; выход удаляет её на сервере. Чувствительные действия ограничены по частоте, изменения с другого Origin блокируются.

Sites дополнительно может передавать свою проверенную identity. Эта интеграция включается только переменной `TRUST_SITES_IDENTITY=true` на хостинге Sites. При самостоятельном деплое оставьте `false`: произвольный HTTP-клиент может подставить такие заголовки напрямую, поэтому доверять им на обычном Worker нельзя. Собственная авторизация не использует и не переопределяет служебные маршруты Sites.

## Интерфейс

`app/platform.tsx` — оболочка и навигация; `components/catalog.tsx` — главная, каталог, анкета; `components/workspace.tsx` — кабинеты; `components/dialogs.tsx` — формы; `lib/i18n.ts` — русский и узбекский интерфейс. Пользовательские описания остаются на языке автора. Фильтры сохраняются в query string; в localStorage хранится только язык интерфейса. Учебные данные находятся на сервере.

Сообщения обновляются опросом каждые 7 секунд в открытой переписке, уведомления кабинета — каждые 30 секунд. Это не WebSocket-чат. Существующий REST API можно использовать для будущего мобильного клиента с собственной cookie jar; мобильный интерфейс и push-уведомления потребуют отдельной реализации.

## Что требуется для коммерческого запуска

Первая версия реализует основные учебные сценарии, но не является полным аналогом всех существующих платформ. Следующие модули ещё не реализованы:

- Подтверждение email, самостоятельный сброс пароля, смена пароля и удаление аккаунта.
- Payme/Click, чеки, комиссии, подписки, возвраты и учёт реальных платежей. Запись сейчас не списывает деньги.
- Встроенная видеосвязь, запись уроков, мобильное приложение и push/SMS/email-уведомления.
- Команды центра с отдельными преподавательскими аккаунтами и филиалами, посещаемость, повторяющееся расписание, массовая выдача задания группе.
- Верификация преподавателей, загрузка фото и сертификатов, модерация отзывов, жалобы, антиспам/CAPTCHA, проверка файлов антивирусом.
- Родительские кабинеты, отдельные потоки согласия и политики обработки данных, договоры и оферты под выбранную бизнес-модель.
- Масштабирование каталога: сейчас он загружается целиком и фильтруется в браузере; для большого количества анкет нужны серверная пагинация, индексы и поиск.

До публичного набора пользователей нужно согласовать эти модули, правила платформы, обработку данных и эксплуатацию. Демонстрационные анкеты из `lib/catalog.ts` содержат вымышленные сведения и явно отмечены; перед запуском их можно удалить одним массивом.
